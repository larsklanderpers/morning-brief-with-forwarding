# Kimi K3 open weights — 27 July

**What happened.** Moonshot's K3 (sparse MoE, ~2.8T params, 1M context) has its API
live now with open weights releasing 27 July. Reported to match Claude Opus 4.8 on
measured intelligence and to top frontend coding benchmarks.

**Why it matters.** Frontier-class capability that can run inside your own building
is the event the sovereignty argument has been waiting for. It converts "local models
are a compromise" into "why is customer PII still leaving the building?" — and it
lands the same fortnight as CPS 230, the EU AI Act, and the Privacy Act ADM clause.
The complication is provenance: Chinese-origin weights need an explicit risk
assessment, not an assumption, so the real question becomes *which* local, under
whose governance norms, auditable by whom.

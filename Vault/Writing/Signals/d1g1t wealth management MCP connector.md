# d1g1t ships an MCP connector into advisory workflows

**What happened.** First major wealth management platform to bridge MCP natively to Claude,
ChatGPT and Copilot inside adviser workflows.

**Why it matters.** Wealth management is among the highest-PII environments there is, and MCP
is a protocol for handing tools and data to a model. The questions this will face — which data
flows to which model, where it goes afterward, who holds the record — are the ones Ken Huang
has been raising about MCP security generally, now with a named regulated deployment attached.
Early movers set the pattern the rest of the sector defends, which makes this worth watching
rather than just noting.

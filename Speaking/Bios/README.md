# Bios — which one to use where

All bios are the same facts at different lengths and in both persons. Pick by field size and venue convention, not by preference.

| File | Words | Person | Use for |
|---|---|---|---|
| `bio-micro.md` | ~45 | 3rd | Program books, session cards, name badges, panel intros |
| `bio-short.md` | ~70 | 3rd | Tight form fields, podcast show notes, meetup listings |
| `bio-med-third-person.md` | ~125 | 3rd | Tech conference speaker profiles. **Conf42 uses this one.** |
| `bio-med-first-person.md` | ~125 | 1st | Venues that ask in first person, or where the form is clearly conversational |
| `bio-long-first-person.md` | ~270 | 1st | 300-word CFP bio fields. **PerthSEC used this one.** |
| `bio-long-third-person.md` | ~270 | 3rd | 300-word fields at venues that publish third person |

## Rules

- **Spelling.** Australian (-ise) for AU venues, US (-ize) for US and global tech venues. Each file is written in the spelling that matches its typical use; check before pasting.
- **Company name.** Every bio says Player Elite. The Australian LinkedIn profile must agree with whatever is on the form, because reviewers search. See `../PerthSEC-2026/decisions.md`.
- **The last line does the work.** In every version the closing clause establishes that he personally builds and runs the AI agents the talks are about. That is the warrant. Do not trim it to save words -- trim the middle instead.
- **Never edit a bio in a form field.** Edit the file, then paste. Otherwise the record drifts from what was actually submitted.

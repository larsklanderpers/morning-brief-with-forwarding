# Research Note -- Windows builds a native stack for local models and agents

For: Thu 1 Oct The Model Moves Onto the Desk · Depth: deep · Date: 2026-09-25

## Bottom line

The thesis survives, but only in a narrower form than the seed implies. Microsoft does state a ship date, and it is on a primary: Microsoft Learn says Aion Instruct, the in-box on-device model that replaces Phi Silica behind the Windows AI APIs, "begins rolling out to Windows Insider Preview devices in October 2026 and to retail devices in November 2026." That is a month, not a day, and "ordinary Windows machines" overstates it: the in-box language model path still needs a Copilot+ NPU, or (experimental today) an RTX 30-series / Radeon RX 9060-series GPU with 6 GB+ of VRAM. Most of the four seed items are not September news: Windows ML went GA on 23 Sep 2025, the On-Device Agent Registry went to public preview at Ignite on 18 Nov 2025, MXC was announced in early preview at Build on 2 Jun 2026; the Pragmatic Engineer piece (22 Sep 2026) is a re-report and synthesis, and the genuinely new September items are Project Zenith (4 Sep), the 7 Oct Windows/Surface event on "local AI," and the Aion retail timeline.

## What's solid

- **Windows ML is GA, and has been for a year.** "Generally available for production use" on 23 Sep 2025; requires Windows 11 24H2 or newer; runs on CPUs, GPUs and NPUs from AMD, Intel, NVIDIA and Qualcomm through vendor "execution providers"; ships in Windows App SDK 1.8.1+. No Copilot+ requirement. -- Microsoft, Windows Developer Blog (primary): https://blogs.windows.com/windowsdeveloper/2025/09/23/windows-ml-is-generally-available-empowering-developers-to-scale-local-ai-across-windows-devices/ . First introduced at Build 2025, 19 May 2025 (primary): https://blogs.windows.com/windowsdeveloper/2025/05/19/introducing-windows-ml-the-future-of-machine-learning-development-on-windows/ . Note: the current Learn overview (updated 6 Aug 2026) lists Windows ML as "Windows 10 and later PCs and cross-platform," which conflicts with the GA post's 24H2 floor. Cite the Learn page for current state: https://learn.microsoft.com/en-us/windows/ai/overview
- **On-Device Agent Registry (ODR) is a preview MCP server registry, announced Nov 2025.** Public preview announced at Ignite 2025 (18 Nov 2025), described as a "secure, manageable repository of agent connectors, which are just MCP servers," alongside native MCP on Windows and built-in File Explorer and Settings connectors. -- Microsoft, Windows Developer Blog (primary): https://blogs.windows.com/windowsdeveloper/2025/11/18/ignite-2025-furthering-windows-as-the-premier-platform-for-developers-governed-by-security/ . The CLI (odr.exe) has `odr mcp list / add <manifest> / remove / configure / run`; page carries the pre-release disclaimer; last updated 18 Nov 2025. -- Microsoft Learn (primary): https://learn.microsoft.com/en-us/windows/ai/mcp/odr-tool . Pragmatic Engineer (22 Sep 2026) independently describes it as still beta and acting as a proxy between MCP clients and servers.
- **MXC is an early-preview, open-source (MIT) sandbox, announced at Build 2026 (2 Jun 2026).** "A cross-platform, policy-driven execution layer for agents on Windows and WSL"; process and session isolation "shortly after Build"; micro-VM, Linux containers and Windows 365 integration on the roadmap; partners named: GitHub, Nous Research (Hermes), Manus, NVIDIA, OpenAI, OpenClaw. -- Windows Developer Blog (primary): https://blogs.windows.com/windowsdeveloper/2026/06/02/windows-platform-security-for-ai-agents/ . The repo says Windows 11 24H2+ and, verbatim, "no MXC profiles should be treated as security boundaries currently." -- GitHub, Microsoft (primary): https://github.com/microsoft/mxc
- **The dated ship claim: Aion Instruct replaces Phi Silica, Insider in October 2026, retail in November 2026.** Verbatim: "Aion Instruct begins rolling out to Windows Insider Preview devices in October 2026 and to retail devices in November 2026, at which point Phi Silica will be removed." Phi Silica page adds: sideloadable test package "early October 2026," and LAF (Limited Access Feature) tokens no longer needed with Aion. -- Microsoft Learn (primary): https://learn.microsoft.com/en-us/windows/ai/apis/ and https://learn.microsoft.com/en-us/windows/ai/apis/phi-silica (updated Jul/Aug 2026). WindowsForum (28 Jul 2026, secondary, citing a Microsoft transition plan) gives the specific day 24 Nov 2026; primary says month only.
- **Hardware floor for the in-box model.** NPU on Copilot+ PCs ("best performance," model pre-installed); GPU path on NVIDIA GeForce RTX 30+ or AMD Radeon RX 9060+ with 6 GB+ VRAM, but currently requires Developer Mode, an Insider Experimental Channel build 26300.8553+, Windows App SDK 2.2.2-experimental9, and beta/manufacturer drivers; GPU path downloads the model on demand and lacks prompt compression and speculative decoding. CPU support covers Speech Recognition and Video Super Resolution only. -- Microsoft Learn (primary), same two URLs.
- **Foundry Local is GA and ships Qwen among others.** GA; Windows, macOS (Apple silicon), Linux; catalog includes GPT OSS, Qwen, DeepSeek, Mistral, Phi, Whisper; OpenAI-compatible API; ~20 MB runtime; "no per-token costs," no Azure subscription. -- Microsoft Learn (primary, updated 4 Aug 2026): https://learn.microsoft.com/en-us/azure/foundry-local/what-is-foundry-local . So "Qwen on Windows" is solid via Foundry Local, independent of any Surface demo.
- **Aion 1.0 family announced at Build 2026.** Aion 1.0 Instruct (small, replaces Phi Silica) and Aion 1.0 Plan (a 14B-parameter agentic model, in-box "on capable Windows devices in coming months," no date). Instruct is also in Edge Canary/Dev for the Prompt API. -- Microsoft Edge Blog (primary): https://blogs.windows.com/msedgedev/2026/06/02/expanding-on-device-ai-in-microsoft-edge-new-models-and-apis-for-the-web/ ; Visual Studio Magazine (secondary, 2 Jun 2026) for the 14B figure: https://visualstudiomagazine.com/articles/2026/06/02/at-build-2026-microsoft-sets-up-windows-as-an-os-for-ai-agents.aspx
- **Surface RTX Spark Dev Box.** NVIDIA RTX Spark (Blackwell RTX GPU + Grace CPU), up to 1 petaflop AI compute, 128 GB unified memory, "run 120B+ parameter models with 1 million token context locally at interactive speeds"; "available later this year in the U.S. exclusively on Microsoft.com"; no price; pre-release, FCC-conditional. -- Microsoft Devices Blog (primary, 2 Jun 2026): https://blogs.windows.com/devices/2026/06/02/building-the-next-generation-of-devices-for-developers-surface-rtx-spark-dev-box/ and product page https://www.microsoft.com/en-us/surface/devices/surface-rtx-spark-dev-box
- **Windows 11 installed base: one billion users.** Nadella, FY26 Q2 earnings (Jan 2026): "One billion Windows 11 users, up over 45% year-over-year." -- Microsoft Investor Relations (primary): https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q2
- **"Unmetered intelligence" is Microsoft's own framing.** Nadella on X (Build week): "Unmetered intelligence on every desk and in every home with Windows. New Aion on-device models, bringing Windows AI APIs to a broader install base..." -- primary: https://x.com/satyanadella/status/2061896505481658767 ; repeated by Windows CVP Mark Linton at IFA (Windows Latest, 8 Sep 2026, secondary): https://www.windowslatest.com/2026/09/08/microsoft-revives-bill-gates-pc-on-every-desk-promise-for-windows-11-now-it-means-ai/
- **Microsoft itself warns about agent risk.** Experimental agentic features are "off by default," can be enabled only by an admin and then apply to all users; Microsoft names cross-prompt injection ("malicious content embedded in UI elements or documents can override agent instructions, leading to unintended actions like data exfiltration or malware installation") and hallucination. -- Microsoft Support (primary): https://support.microsoft.com/en-us/windows/ai/ai-features/experimental-agentic-features

## What's contested / watch out

- **"Ordinary Windows machines."** The in-box model is not on the median PC. Retail November rollout is clearly the NPU path; the GPU path is still Insider Experimental with beta drivers, and Microsoft has not said the GPU path reaches retail in November. Copilot+ PCs were 2.3% of Windows PCs shipped in Q1 2025 per IDC (via PCWorld, 18 Jun 2025, secondary; IDC primary not reached). Say "Copilot+ class machines, with a GPU path in testing," not "every Windows PC."
- **Windows ML and Foundry Local are the broad layer; Aion is the narrow one.** Windows ML and Foundry Local run on CPUs/GPUs/NPUs broadly, but the developer has to bring and ship the model. The in-box, pre-installed, free model (the part that makes it "the OS ships a model") is the NPU-gated piece. Do not blur the two.
- **Copilot+ brand is being retired.** Windows Central (Zac Bowden, 24 Sep 2026, secondary) quotes Surface CVP Brett Ostrum that 2026 Surfaces "are not called Copilot+ PCs" though they meet the requirements; Qualcomm's Kedar Kondap similar. The spec survives; the label does not. Useful color, single secondary.
- **RAM is the scarce input, and local AI is RAM-hungry.** IDC (Jitesh Ubrani, Jean Philippe Bouchard, 2 Jun 2026, primary blog): 2026 PC shipments forecast down 11.3%, Q4 down 20% y/y, driven by DRAM/NAND shortage; "We're not seeing any relief to the memory shortage situation before the end of 2027." https://www.idc.com/resource-center/blog/pc-market-enters-volatile-territory-as-memory-shortage-persists-through-2027/ . Windows Central (secondary) reports OEMs shipping 8 GB budget configs. Project Zenith's floor is 64 GB unified memory. The upbeat thesis has to meet this head-on: the model moves onto the desk at the exact moment memory is the one thing the desk cannot cheaply get.
- **NPU underuse.** PCWorld (Chris Hoffman, 19 Nov 2025, secondary): LM Studio, Ollama and llama.cpp do not use NPUs; "the most popular apps don't use NPUs at all. They may never even transition to Windows ML." Microsoft's own pivot to GPU and CPU paths for the Windows AI APIs at Build 2026 is consistent with this. Single secondary for the quote; the pivot itself is primary.
- **Headline hardware claims are vendor numbers.** "120B+ parameters at interactive speeds" is Microsoft/NVIDIA, not independently benchmarked (Gadget Hacks, 8 Jun 2026, secondary).
- **Windows 11 share is noisy.** StatCounter shows 68.6% of Windows in Aug 2026 (https://gs.statcounter.com/windows-version-market-share) versus 72.57% reported for Feb 2026 (The Register, 2 Mar 2026). Page-view based; do not print a precise share without the method caveat. Prefer Nadella's "one billion" and attribute it.
- **Windows ML version floor.** GA post says Windows 11 24H2+; current Learn overview says Windows 10 and later. Cite whichever you use with its date.

## The economics

- **Per-token cost goes to zero for the developer; it does not go to zero.** Foundry Local: "no per-token costs," no Azure subscription (Microsoft Learn, primary). Aion via Windows AI APIs is in-box and, after the transition, needs no LAF token (primary). The developer's marginal cost of an inference on the user's machine is roughly nil.
- **Who pays: the device owner, up front, plus electricity.** The cost moves from metered opex (per million tokens to a cloud provider) to capex already sunk in the PC (NPU, GPU, RAM) and a small power bill. The sharpest phrasing found: "'unmetered' describes the billing model, not the cost: it converts a variable per-token charge into fixed hardware capex" (Pickuma, 2 Jun 2026, secondary commentary; https://pickuma.com/for-dev/nadella-build-2026-unmetered-intelligence/). This is Lars's frame: the bill moves to whoever bought the laptop, which for a CISO/CTO is the fleet budget.
- **Order of magnitude.** A Jan 2026 preprint (Knoop and Holtmann, arXiv 2601.09527, not peer reviewed; consumer Blackwell GPUs, SME server context, not laptops) puts self-hosted electricity-only cost at $0.001 to $0.04 per million tokens at $0.12/kWh, "40-200x cheaper than budget-tier cloud APIs," with hardware break-even under four months at 30M tokens/day. https://arxiv.org/html/2601.09527v1 . Cloud anchor: OpenAI's cheapest listed text model (GPT-5.6 Luna) is $0.20 input / $1.20 output per million tokens (OpenAI pricing page, primary, read 25 Sep 2026: https://openai.com/api/pricing/). Use as illustration with the caveats; a laptop NPU running a small model is not a 5090.
- **The catch is quality and capacity, not price.** A small in-box model is not a frontier model; Microsoft's own framing (Linton/Nadella) is hybrid: local for the 30B-and-under class, cloud for frontier. And the capex input that matters, DRAM, is in a shortage IDC says lasts through 2027 -- local inference is cheapest exactly where memory is most expensive.
- **For the enterprise reader.** Fleet refresh, not API budget, becomes the AI line item; Windows 10 end of support (Oct 2025) already pushed that refresh (The Register). The growth story is that a billion-seat install base becomes an inference fleet the vendor does not pay to run.

## Angles this opens

- **Timing hook:** the piece runs 1 Oct; Microsoft's Windows and Surface event on "local AI" is 7 Oct; Aion hits Insider devices in October and retail in November. The piece can say the dated milestones out loud before the keynote does.
- **The bill moves to the desk.** "Unmetered" is a billing model, not a cost model. Who pays for inference when the OS ships the model: the fleet owner, via refresh cycles. Upbeat version: a billion-seat inference fleet nobody pays per token to run.
- **Memory is the new NPU.** Microsoft's own developer floor (Zenith: 64 GB, 250 GB/s) versus IDC's memory shortage through 2027 and 8 GB budget laptops. The growth story is real and the constraint is DRAM, not TOPS.
- **Microsoft quietly un-NPU-ing its AI stack.** Copilot+ branding retired, Windows AI APIs extended to GPUs and CPUs, Windows ML hardware-agnostic. The platform is bending toward the hardware people actually own -- the most upbeat and defensible version of the thesis.
- **Developer default switch.** OpenAI-compatible local endpoint (Foundry Local) plus an in-box model means "try local first, fall back to cloud" becomes a one-line change. Worth a follow-up with a developer who has shipped it.

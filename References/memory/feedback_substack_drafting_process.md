**Rule:** Before drafting any new Substack piece, read ALL existing drafts in `Substack Drafts\` (not just the index). Do not draft from the brief alone.

**Why:** Lars wants voice consistency that accumulates across the series, and narrative threads to be consciously tracked — with callbacks to earlier pieces and forward references when a multi-day arc is forming.

**How to apply:**

1. Read `SUBSTACK_INDEX.md` first to map the full corpus.
2. Read each draft file in full — both Published and Draft status — before writing anything new.
3. Identify recurring narrative threads (e.g. "Hollywood vs. grind", the AI accountability arc, the regulatory lag motif) and either:
   - **Call back** to a prior piece by title or theme if the new piece builds on it.
   - **Forward reference** if a multi-day series is being set up (e.g. "We'll get to X tomorrow").
4. Note which beats (Cyber / AI Security / Policy / Privacy / Clubs) have run recently — avoid clustering the same beat too many days in a row without intent.
5. LinkedIn posts: **skip for now**. Focus exclusively on Substack until the voice and thread structure are dialed in.

**Tone continuity:** Cross-reading the corpus is how voice accumulates. Each new draft should feel like the next chapter, not a fresh start. Reference [[lars-writing-voice]] for sentence-level style.

**Multi-day series detection:** If two or more drafts in the queue clearly develop the same argument or story arc across different angles, flag this to Lars and suggest explicit series framing (Part 1 / Part 2, or thematic callbacks).

The attack chain no longer has a human in it.

That's the sentence security leaders should be sitting with this week. Not as hyperbole. As operational reality.

Three separate stories broke in the last 48 hours that, taken together, mark an inflection point.

**First:** Researchers demonstrated a self-replicating AI worm that operates entirely on local, open-weight models — no cloud API, no network dependency for the AI reasoning component. It propagates through agent-to-agent interactions. The significance isn't the worm itself. It's that every cloud-side safety control ever built — provider monitoring, rate limiting, content filtering — is now irrelevant to a new class of autonomous threat.

**Second:** Security firm AIR published a fake AI agent skill to a popular marketplace, ran an Instagram ad, and watched it load into approximately 26,000 agents — including corporate accounts — before a single scanner flagged it. Every skill security tool tested marked it safe. The payload was deliberately benign. The lesson is not. AI agent skill marketplaces are repeating every mistake mobile app stores made in 2011, at 10x the speed, with significantly higher privilege.

**Third:** A new CI/CD vulnerability class called "Cordyceps" was disclosed affecting 300+ high-impact GitHub repositories — including those belonging to Microsoft, Google, Apache, and Cloudflare. Exploitable by any unauthenticated user with a free GitHub account. No special privileges required. Full code execution, credential theft, and supply chain compromise.

These aren't coincidental. They're convergent.

We built cybersecurity operations around a model where attack chains require human decision-making at each stage. A human writes the phishing email. A human reviews the stolen credentials. A human decides when to deploy the payload. That model created the rhythms our defences run on: 30-day patch cycles, weekly threat intel reviews, SOC analyst escalation chains.

Those rhythms are now dangerously mismatched to the threat.

Agentic AI doesn't wait for business hours. It doesn't need to sleep between reconnaissance and exploitation. The FortiBleed operation — which harvested credentials from 430,000 FortiGate firewalls using a passive Golang sniffer — ran for four months before detection. Not because the indicators weren't there. Because the operation moved below the threshold of human-review cadences.

The defensive posture that survives this transition looks fundamentally different. Machine-speed detection. Pre-authorised response playbooks. Approved-skill-list governance for AI agent deployments. Zero-trust architecture that assumes any component of your pipeline — including your CI/CD, your development agents, and your security tooling — can be compromised.

The organisations that frame this as "we need better scanners" will spend the next two years losing ground. The organisations that frame it as "we need to re-architect for autonomous threat actors" have a chance.

The Trump administration's executive order setting a 2030 deadline for federal post-quantum cryptography migration pulled the prior 2035 timeline forward by five years, citing harvest-now-decrypt-later risks. That's not a policy gesture. That's the government telling you the clock is running faster than previously modelled.

The automated adversary has arrived. The question for every CISO and board member is simple: does your security programme run at human speed or machine speed?

One of those answers is still viable.

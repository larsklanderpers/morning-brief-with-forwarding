Last week, ransomware stopped dairy production in the United States.

Not metaphorically. Coca-Cola's Fairlife subsidiary was hit, and milk stopped moving through the supply chain. Production suspended. A ransomware attack — the kind we've been calling a "cyber problem" for two decades — reached into a physical facility and turned off the machines.

That same week: 570 Microsoft vulnerabilities patched in a single Tuesday. A critical zero-day in Active Directory Federation Services actively exploited in the wild. The ServiceNow AI Platform compromised via an unauthenticated sandbox escape. Hugging Face breached — by an autonomous AI agent that executed the entire kill chain without a human operator.

This isn't a bad week. This is the new baseline.

**The attackers have upgraded. Most organisations haven't noticed.**

The Hugging Face breach is the story I keep coming back to. A threat actor deployed an autonomous agent framework that executed thousands of individual actions across short-lived sandboxes — harvesting credentials, escalating privileges, moving laterally — all without anyone typing commands at a keyboard. Traditional forensics struggled because the attacker's "footprint" was distributed across disposable infrastructure.

Meanwhile, North Korean operators from the Contagious Interview campaign are now hiding four-stage malware inside SVG image files with zero antivirus detections. They're targeting developers — the people with access to source code, CI/CD pipelines, and cloud API keys — via fake coding assessments. Economic anxiety in the tech sector has become an attack vector.

**The AI governance gap is now a security gap.**

Security researchers confirmed this week that threat actors are using AI coding assistants to automate multi-stage campaigns. The same tools that help developers write faster help attackers attack faster. Most organisations have deployed these tools with acceptable-use policies and no technical controls. That's not a policy problem — it's an architecture problem.

AI agents need to be treated as privileged identities. They need access controls, behavioural baselines, monitoring, and rate-limiting — the same controls we apply to privileged human users. The organisations that figure this out in the next 12 months will be measurably more resilient. The ones that don't will discover it during an incident.

**The board conversation has to change.**

When the CISA-NSA-FBI joint advisory is about router hygiene and Russian pre-positioning in critical infrastructure — when a record Patch Tuesday drops 570 CVEs including an actively exploited ADFS zero-day — when ransomware is physically halting food production — the framing of "cyber as IT problem" is no longer defensible.

The question for every executive leadership team right now isn't whether your security team has enough budget. It's whether your risk model reflects what the threat environment actually looks like in mid-2026.

Because the attackers updated their model. The question is whether yours has kept pace.

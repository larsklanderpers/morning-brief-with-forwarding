## 🚨 Government Advisories

**#StopRansomware: Gunra Ransomware | CISA Advisory AA26-222A**
Source: CISA / FBI / NSA / DoD Cyber Crime Center | [Advisory](https://www.cisa.gov/news-events/cybersecurity-advisories/aa26-222a)

Joint advisory from CISA, FBI, NSA and allied partners warning that Gunra ransomware — a Conti-derived RaaS variant launched in April 2025 — is actively targeting healthcare, financial services, government, and critical infrastructure globally. Initial access is via CVE-2024-55591 and CVE-2025-24472 in internet-facing devices. Double-extortion model; dark web leak site active.

💡 **Strategic take:** Gunra is the latest proof that leaked ransomware source code has a long shelf life. The Conti ecosystem continues to spawn affiliates years after the group's collapse — any org that patched Conti-era CVEs and moved on is now re-exposed by the same tradecraft in a new wrapper. Healthcare and financial services boards need to treat RaaS not as a one-time incident class but as a structural cost of operations.

**CISA Adds Seven Known Exploited Vulnerabilities to Catalog (Sept 2)**
Source: CISA | [Alert](https://www.cisa.gov/news-events/alerts/2026/09/02/cisa-adds-seven-known-exploited-vulnerabilities-catalog)

Seven CVEs added 2 September: Sangoma Switchvox (SQL Injection), Kludex Starlette (HTTP Request/Response Smuggling), Kestra OSS (OS Command Injection), BerriAI LiteLLM (Improper Authentication), JFrog Artifactory (Improper Authentication), and two SonicWall SMA1000 vulnerabilities (CVE-2026-83548 CVSS 10, CVE-2026-83549). FCEB agencies deadline: most by Sept 5, Starlette/LiteLLM by Sept 16.

💡 **Strategic take:** The LiteLLM and BerriAI inclusions are significant — these are AI infrastructure components, not traditional enterprise software. Their presence in CISA's KEV catalog signals that the AI tooling layer is now firmly in scope for nation-state and criminal exploitation. If your AI platform stack hasn't been through a security review, the federal government just told you why it should be.

**CISA Adds Chrome V8 Zero-Day CVE-2026-85046 (Sept 4)**
Source: CISA | [Alert](https://www.cisa.gov/news-events/alerts/2026/09/04/cisa-adds-one-known-exploited-vulnerability-catalog)

Google Chromium V8 Type Confusion vulnerability added to KEV catalog 4 September. Active exploitation confirmed. Browser vendors have issued patches; FCEB agencies required to remediate promptly.

For Australian MSPs and their clients, this is a supply-chain risk event, not just a patch management task.

## 📰 Top Security News

**ASUS Control Center Enterprise: Max-Severity RCE Vulnerability**
Source: Cybersecurity News | [Coverage](https://cybersecuritynews.com/)

Researchers have disclosed a maximum-severity (CVSS 10) vulnerability in ASUS Control Center Enterprise (ACC) that allows remote attackers to seize full control of affected systems without authentication. ASUS has issued an emergency patch.

💡 **Strategic take:** Enterprise management software with CVSS 10 scores and no authentication requirement is as bad as it gets — it's a skeleton key for any environment where ACC is deployed. The patch is out; the window between patch release and adversary exploitation is now measured in hours, not days.

Source: SecurityWeek / Cybernews | [Coverage](https://www.securityweek.com/)

An unauthenticated remote access vulnerability in MikroTik RouterOS is being actively exploited. Network administrators worldwide are urged to patch immediately. MikroTik hardware is widely deployed in ISPs, enterprises, and small business networks globally.

**Broadcom VMware VMSA-2026-0007: VM Escape in Workstation and Fusion**
Source: Cybersecurity Newsletter | [Coverage](https://cybersecuritynews.com/weekly-cybersecurity-newsletter-bulletin-sept-2026/)

**SonicWall SMA1000: CVSS 10 + Chained OS Command Execution Under Active Exploitation**
Source: Rapid7 | [Analysis](https://www.rapid7.com/blog/post/etr-critical-sonicwall-sma1000-vulnerabilities-cve-2026-83548-cve-2026-83549-exploited-in-the-wild/)

CVE-2026-83548 (CVSS 10, SSRF) and CVE-2026-83549 (OS command execution) in SonicWall SMA1000 are being actively exploited in a chained attack sequence enabling unauthenticated remote command execution. Both CVEs are on CISA's KEV catalog.

💡 **Strategic take:** A chained pair where the first bug enables the second without authentication is about as clean as exploit chains get. SonicWall SMA1000 is a network access appliance — it sits at the perimeter by design. This isn't just a patch-and-move-on; organisations should audit SMA1000 logs for indicators of prior access before applying the fix.

## 🤖 AI & Security

**Ransomware Crew Socially Engineers Coding Agent Safety Refusals During Live Intrusion**
Source: Cybersecurity Trends / CSA Lab | [Coverage](https://labs.cloudsecurityalliance.org/research/alt-ciso-briefing-2026-09-01/)

A documented incident confirmed that a ransomware operator socially engineered a commercial AI coding agent's safety guardrails during a live intrusion — using the agent to assist with intrusion tasks by bypassing its built-in refusals through iterative prompt manipulation.

💡 **Strategic take:** This is the first documented case of adversarial guardrail bypass against a production AI agent being used as an intrusion tool. It validates what red teams have been demonstrating in controlled environments for two years: safety refusals are a speed bump, not a wall. AI agents with access to code repositories, terminals, or APIs need the same access controls as human operators — and probably tighter.

**Wiz Threat Research: MCP Server Attack Patterns — RCE Chaining, Blind Prompt Injection, API Key Theft**
Source: Wiz Threat Research | [Coverage](https://www.fortinet.com/resources/cyberglossary/cybersecurity-trends-2026)

Wiz has identified three distinct attack patterns against AI agent infrastructure: MCP server RCE chaining (exploiting vulnerabilities in Model Context Protocol servers), blind prompt injection targeting agent frameworks to redirect tool calls, and post-exploitation tooling built specifically to extract LiteLLM in-memory API keys.

💡 **Strategic take:** MCP is the plumbing of the agentic AI ecosystem — it connects agents to tools, APIs, and data sources. Attack tooling being purpose-built for MCP exploitation means this isn't theoretical anymore. The AI infrastructure layer (MCP servers, LiteLLM proxies, agent orchestration frameworks) now has a dedicated threat actor attack surface that most security teams have not inventoried, let alone protected.

## 📌 Today's Signal

The convergence point in today's brief is this: the attack surface has bifurcated, and most organisations are only managing half of it. The traditional surface — routers, VPNs, management planes, e-commerce platforms — is as busy as ever (SonicWall, MikroTik, vCenter, Magento, ASUS). But a second surface has materialised in the AI infrastructure layer: MCP servers, LLM proxies, coding agents, agentic orchestration frameworks. Wiz is documenting purpose-built attack tooling against that layer. A ransomware crew has already weaponised it in a live intrusion. CISA just added two AI infrastructure CVEs to its KEV catalog. The organisations that will avoid the next generation of serious incidents are the ones that have inventoried both surfaces — not just the one they've been managing for the last twenty years.

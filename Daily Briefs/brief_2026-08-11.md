## 🚨 Government Advisories

### #StopRansomware: Gunra Ransomware
**Source:** CISA (joint advisory with FBI, DoD Cyber Crime Center, NSA, USSS, Republic of Korea NPA) | [Advisory AA26-222A](https://www.cisa.gov/news-events/cybersecurity-advisories/aa26-222a)

A multi-agency joint advisory warns of the Gunra ransomware group, a double-extortion operation derived from the leaked Conti source code, first observed in April 2025. CISA urges organisations to patch exposed VPNs and implement network segmentation as primary mitigations. Victims are concentrated in critical infrastructure and enterprise sectors.

💡 **Strategic take:** Conti's source code leak in 2022 continues to pay dividends for threat actors four years later — Gunra is at least the third significant Conti-derived strain to reach this level of operational maturity. The multi-agency, multi-national advisory signals that Gunra has already caused harm in government-adjacent targets. For decision-makers: if VPN patching has slipped in the queue, Gunra moves it to the top.

### CISA KEV: CVE-2026-8037 — Progress LoadMaster Command Injection
**Source:** CISA KEV Catalog | [Senserva KEV Tracker](https://senserva.com/exploited-this-week.html)

CISA added CVE-2026-8037 (Progress LoadMaster command injection) to the Known Exploited Vulnerabilities catalog on 7 August, with an EPSS score of 99% — effectively certain to be exploited if unpatched. LoadMaster is a widely deployed application delivery controller used in enterprise and government environments.

💡 **Strategic take:** An EPSS of 99% is not a threat model, it's a timer. LoadMaster sits on the ingress path for applications — compromise here means an attacker who controls routing decisions, not just access. Any organisation running LoadMaster should treat this as an active incident response exercise, not a patch-cycle item.

**Source:** CISA | [KEV Catalog](https://www.cisa.gov/news-events/alerts/2026/08/04/cisa-adds-three-known-exploited-vulnerabilities-catalog)

CISA added three further exploited vulnerabilities on 4 August: CVE-2026-9198 (IBM Langflow Code Injection), CVE-2026-18556 (N-able N-central Authentication Bypass), and CVE-2026-34486 (Apache Tomcat Missing Encryption of Sensitive Data). 💡 **Strategic take:** An auth bypass in N-central isn't a single customer problem, it's a supply chain problem. MSPs running N-central without the patch are a lateral movement vector into every organisation they manage. If you use a managed service provider, ask them specifically about CVE-2026-18556 remediation status — this week, not next quarter.

### ACSC: ClickFix Campaign Targeting Australian Networks via Compromised WordPress Sites
**Source:** Australian Cyber Security Centre | [cyber.gov.au](https://www.cyber.gov.au/about-us/view-all-content/alerts-and-advisories)

The ACSC is tracking an active ClickFix social engineering campaign distributing malware through compromised WordPress websites targeting Australian networks. Separately, the ACSC is tracking a large-scale exploitation campaign against web content management systems globally, including in Australia, and an active campaign against Fortinet firewalls and VPN gateways. The ACSC also published updated board-level guidance on AI cyber threats (5 August) and updated SBOM minimum elements guidance.

💡 **Strategic take:** ClickFix is deceptively simple — users are shown a fake error message and instructed to paste a command into their terminal. No exploit needed, no zero-day required. The Australian targeting through legitimate (but compromised) WordPress sites means domain reputation doesn't protect you. Security awareness training that doesn't specifically address ClickFix-style lures is already out of date.

## 📰 Top Security News

### DeadLock Ransomware Uses Blockchain C2 to Evade Detection
**Source:** Microsoft Security Blog, 10 August 2026 | [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/08/10/deadlock-ransomware-breaking-down-a-rust-based-encryptor-with-decentralized-recovery-infrastructure)

Microsoft published a detailed technical breakdown of DeadLock, a Rust-based ransomware operation that routes its command-and-control infrastructure through Polygon smart contracts — making takedown by seizing traditional C2 servers effectively impossible. DeadLock disables Windows Defender, deletes shadow copies, and clears event logs before encryption. Over 80 organisations have been listed on its data leak site, with more than half the claimed victims in Europe. Double extortion is the standard playbook: data exfiltration precedes encryption.

💡 **Strategic take:** Blockchain-based C2 is the adversary's answer to the infrastructure takedown playbook that has worked against traditional ransomware for the past decade. CISA and Europol can seize domains; nobody seizes Polygon. Decision-makers need to shift their ransomware resilience thinking from "disrupt the attacker's infrastructure" (now much harder) to "shrink your own blast radius" — network segmentation, offline backups, and least-privilege access that limits what an encryptor can reach when it lands.

### Abyssos RAT: Modular Credential Theft with Hidden VNC
**Source:** Zscaler ThreatLabz / GBHackers | [GBHackers](https://gbhackers.com/abyssos-rat-hijacks-browser-sessions/)

First identified by Zscaler ThreatLabz in late June 2026, Abyssos is a new modular RAT written in C++ with active development. Its capabilities include hidden VNC sessions, credential theft from Chrome and Brave via the Chrome DevTools Protocol (remote debugging on port 9222), cookie exfiltration, keylogging, and downloadable additional modules from C2. Initial access in one observed attack used DLL sideloading via `DiskIntegrityScanner.exe`.

💡 **Strategic take:** The Chrome CDP abuse is the mechanism worth flagging to your security team. Most endpoint controls focus on file-based indicators; Abyssos uses a legitimate browser debugging interface to exfiltrate credentials without touching disk in the traditional sense. Organisations running browser isolation or restricting DevTools Protocol access at the network level are materially better positioned than those relying solely on signature-based detection.

### Red Hat Kubernetes Flaw: Privilege Escalation to Cluster-Admin
**Source:** Security Week / Cybersecurity News

A newly disclosed flaw in Red Hat Kubernetes allows an attacker to escalate privileges to cluster-admin level. Kubernetes clusters frequently host sensitive workloads across multiple tenants; cluster-admin access effectively means full control of every workload and secret in the cluster.

💡 **Strategic take:** Kubernetes privilege escalation vulnerabilities tend to have outsized blast radius because organisations have consolidated workloads under the assumption that internal cluster boundaries are enforced. If you're running Red Hat OpenShift or vanilla Kubernetes on Red Hat-flavoured infrastructure, check your patch status now. This is the kind of vulnerability that sits quietly for weeks before someone weaponises it in a ransomware pre-positioning campaign.

### Ransomware Wave: Helix Hits Morguard; Clop Claims FIS Global (874GB)
**Source:** BreachSense / BrightDefense | [BreachSense](https://www.breachsense.com/breaches/2026/august/)

The Helix ransomware group targeted Morguard Corporation (Canadian real estate) on 7 August and has separately targeted Highwoods Properties (US real estate). The Clop group claims to have exfiltrated 874GB from FIS Global, a major financial services infrastructure provider whose systems underpin payment processing and core banking for many institutions. 💡 **Strategic take:** Clop targeting FIS Global is the item to watch here. FIS processes transactions for thousands of financial institutions globally; 874GB of exfiltrated data in that context likely includes customer data, transaction records, and potentially technical architecture details that enable downstream fraud. The real estate sector (Morguard, Highwoods) holds significant personal and financial data for tenants and investors — these aren't IT problems, they're liability events.

## 🤖 AI & Security

### OpenAI GPT-5.6-Cyber: 95% Exploit Task Completion, V8 Zero-Day Discovery
**Source:** VentureBeat / Help Net Security / CyberPress | [VentureBeat](https://venturebeat.com/technology/openai-launches-gpt-5-6-cyber-with-reduced-refusals-95-completion-on-advanced-cybersecurity-tasks)

OpenAI released GPT-5.6-Cyber, accessible only through Daybreak Red (its vetted offensive security access program). The model completes 95% of exploit chain development, authentication bypass, and privilege escalation tasks — compared to 1.5% for the standard safeguarded GPT-5.6 Sol. Real-world discoveries include two V8 JavaScript engine flaws that could be chained to escape the Chrome sandbox (CVE-2026-15903, fixed by Google), five mobile OS vulnerabilities, three critical RCE issues in a widely-used database, and over 400 privilege-escalation flaws in a popular OS kernel. OpenAI classifies it as "High" under its Preparedness Framework.

💡 **Strategic take:** The 95% vs 1.5% completion gap is the key number. OpenAI has essentially built a model that can do the work of an offensive security researcher on demand — and it has found real zero-days in production software. The access controls are real (Daybreak Red vetting is rigorous) but they are not permanent barriers. The useful question for decision-makers is not "will attackers get access to tools like this?" but "how do we build resilience assuming they already have?"

### AI Finds 84 Flaws in 5G Core Networks — 23 Still Unpatched
**Source:** Help Net Security / The Hacker News | [Help Net Security](https://www.helpnetsecurity.com/2026/08/11/5g-core-network-vulnerabilities-research/)

Researchers at Nanyang Technological University used iFinder, a tool running three sequential AI agents, to discover 84 vulnerabilities in 4G and 5G core network software. 83 were confirmed, 81 have CVEs assigned, and 23 remain unpatched — including a session hijack vulnerability (CVE-2026-8233) that redirects a subscriber's data traffic to an attacker. At least one major 5G carrier is still working on a fix. The researchers note that 5G cores increasingly run in cloud environments where misconfigured internal interfaces can be exposed to the internet.

💡 **Strategic take:** AI is now finding vulnerabilities in critical telecommunications infrastructure faster than carrier engineering teams can remediate them. The 23 unpatched flaws sitting in live 5G networks used by millions of subscribers are a quiet systemic risk. For enterprise security teams: if your threat model assumes 5G connectivity is secure because it's "carrier-grade," this research says otherwise. Enterprises with sensitive traffic traversing mobile networks should consider end-to-end encryption as a compensating control, not a nice-to-have.

### Claude Code Auto Mode Blocks 89% of Dangerous Commands and Prompt Injection Attacks
**Source:** IT Security News / Cybersecurity News Today

Anthropic's Claude Code autonomous coding agent in auto mode is blocking 89% of dangerous shell commands and prompt injection attacks — including attempts by adversarial content in files or web pages to redirect the agent's actions. This is relevant context as agentic AI systems become more common in enterprise development environments.

💡 **Strategic take:** Prompt injection is the SQL injection of the AI era, and the 11% that gets through at the model layer is still a meaningful attack surface when the agent has filesystem, network, and code execution access. Organisations deploying agentic AI coding tools should treat the agent's permissions with the same scrutiny they'd apply to a contractor: least-privilege access, audit logging, and human approval gates on any action that touches production systems.

## 📌 Today's Signal

The thread running through today's intelligence is the industrialization of offense outpacing the industrialization of defense. Attackers have now solved several problems that security teams once relied on as structural advantages: DeadLock routes C2 through Polygon smart contracts, making infrastructure takedown essentially irrelevant; ClickFix bypasses endpoint controls entirely by social-engineering users into running commands themselves; Abyssos uses a legitimate browser debug interface to exfiltrate credentials without traditional disk-based indicators. Meanwhile, AI is finding vulnerabilities — 84 in 5G infrastructure, zero-days in Chrome's V8 engine — faster than vendors can patch them. Today's SAP CVE cluster (CVSS 10.0, 9.9, 9.8) sitting on enterprise ERP systems suggests attackers are increasingly targeting the actual crown jewels rather than the perimeter. The strategic implication is uncomfortable but clear: the security posture question is no longer "can we keep attackers out" but "what happens to the business when they get in, and how small can we make that blast radius?"

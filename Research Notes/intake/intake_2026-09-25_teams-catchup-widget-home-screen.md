1. ⛔ **The employer is in frame, in plain text, and this is the first image in the run that carries
   it.** The Work item counter widget footer reads **"Site: playerelite"**, above **1058** open work
   items and **2103** reported by him. The Sat 26 board row records that the employer is never named,

   The file is named `..._UNCROPPED.jpg` so the warning travels with it. A crop that starts below the
   Work item counter card still keeps the Teams tile whole, so nothing is lost.
2. ⚠️ **The gold emblem cannot be confirmed generic at this resolution, and line 85 asks for exactly
   that confirmation.** It appears twice: top right of the Teams tile, and as the "Catch up" widget's
   header icon. It reads as a small gold crest or figure. Given finding 1 is an employer string on the
   same screen, the logo question is not academic. **His call, and he is the only one who can answer
   it:** confirm it is a mark he chose for the build, or crop it. Do not assume it is generic because
   the last shot needed no redaction.
3. ⚠️ **The two widgets disagree with each other in frame.** The Teams tile says "Caught up!"; the

   photograph of the piece's payoff also shows 58 unread items, and a reader will see it. If the
   second one is a different app's widget, it is fine and worth a caption word. Either way, decide on
   purpose rather than discover it in the comments. This is the same class of problem as the dock
   badges flagged on the first shot, and it is louder.

   state. The draft's own description of the widget is that it "shows the newest catch-up item and the
   count", and nothing on disk yet shows that. The third graphic (one catch-up card with the chat name
   blurred) would cover it, and it is the one with real redaction risk. A widget-with-an-item shot
   would need the same blur.
5. **Minor, no action needed:** the dock badges are in frame again (phone 1, Slack 3), though
